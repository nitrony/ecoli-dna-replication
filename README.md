# 大腸菌染色体複製のアニメーション

[アニメーションを開く](https://nitrony.github.io/ecoli-dna-replication/)

研究室での説明・レビュー用。26場面、13分40秒、日本語字幕、音声なし。
開始・伸長・成熟の分子機構と、基質に応じた4種類の脱連環反応を比較します。
各単量体を滑らかな分子表面で示し、真の多量体のサブユニット構成を区別します。
分子座標や反応速度は模式表現です。

- [操作できるHTML](index.html)。再生・停止・場面移動・反応段階の選択・視点操作。
- [MP4動画](replication-v7.mp4)。1600 × 1000 px、24 fps。
- [科学的解説と原著29件・参考動画1件](references.md)。DOIと各場面の根拠を掲載。
